      How this page is wired

      One web component, one JSON document. The blueprint declares the options and their prices, and carries a transient inline Filecheck workflow on its file field; so it runs against any tenant with nothing configured in either admin. 

      <print-configurator
  config-url=""
  provider='{"id":"filecheck","mode":"element",
             "publishableKey":"pk_…","preview":true}'
></print-configurator>

      Selections reach the check through the blueprint's filecheck.context patches (size, sides → page count); the file's facts flow back and reprice the form. View the raw blueprint + workflow.
